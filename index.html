Formulas & constants

t_k = t_1 + (k − 1)·(t_analysis + t_post)

I_k = |j_k| · A per injection (or I_k entered directly; blank row = global value)

ṅ_gas (mol s⁻¹) = P · (Q_mL/min · 10⁻⁶ / 60) / (R · T); standard mode uses T = 273.15 K, P = 101325 Pa

ṅ_i = (ppm_i · 10⁻⁶) · ṅ_gas

FE_i (%) = n_i · F · ṅ_i / I · 100

j_i = FE_i/100 · |j_k|; averages are arithmetic mean ± sample SD (n − 1) of the per-injection values

R = 8.314462618 J mol⁻¹ K⁻¹, F = 96485.33212 C mol⁻¹ (CODATA exact). Assumes outlet flow ≈ inlet CO₂ flow (no correction for CO₂ consumption/crossover).
