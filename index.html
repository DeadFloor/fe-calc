Compensation mode

iR-compensated in real time (CI) — E_corr = E_applied (Ru_unc = 0). No post-run correction.

At each GC injection, E_corr = E_applied − I·Ru_uncorrected (cathodic I negative), then convert to RHE with the chosen reference and measured pH.

Ru_unc = Ru·(1 − f_comp). With |I| stored for cathodic runs: E_corr = E_applied + |I|·Ru_unc.

Formulas & constants

t_k (s) = t1_s + (k − 1)·(analysis_min·60 + postrun_s)

I_k = |j_k| · A (FE uses magnitude; iR uses cathodic-negative convention)

ṅ_gas = P · (Q_mL/min · 10⁻⁶ / 60) / (R · T); FE_i = n_i · F · ṅ_i / I · 100; j_i = FE_i/100 · |j_k|

iR / RHE (Faraday): Ru_unc = Ru·(1 − f_comp); with signed cathodic I: E_corr = E_applied − I·Ru_unc; equivalent with stored |I|: E_corr = E_applied + |I|·Ru_unc. If f_comp = 100%, skip correction. E_RHE = E_corr + E°_ref + slope·pH.

Liquid: FE = n·F·(c_WE·V_W + c_CE·V_C)/Q · 100. R = 8.314462618, F = 96485.33212.
